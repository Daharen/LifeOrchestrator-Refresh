# Zorble User Guide

This guide explains how to operate the Zorble system day to day.

## Installation

Install the package and run the setup command. The installer verifies the flux capacitor firmware.

## Configuration

Configuration lives in `config.json`. The key setting is `max_flux`, which bounds throughput.

## Troubleshooting

If you see `E_FROBNICATE_FAILED`, the frobnicator lost sync with the widget. Restart the daemon.
For deeper issues consult decision `D-9999` and the architecture notes.
